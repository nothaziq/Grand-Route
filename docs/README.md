# Grand Route Transport & General Maintenance --- Website

## Project Overview

This project is a professional corporate website for **Grand Route
Transport and General Maintenance L.L.C - S.P.C**, a UAE-based business
operating from Musaffah, Abu Dhabi.

The website should present Grand Route as a credible B2B operator
offering transportation, maintenance, and heavy equipment rental
services.

The design goal is:

> **Industrial editorial + premium UAE corporate**

The website must feel intentionally designed, credible, restrained, and
operational---not like a generic AI-generated corporate template.

## Brand Direction

The existing GRP business card establishes a green, burgundy/red, and
white visual identity. The website should preserve that recognizable
identity while upgrading it into a modern digital system.

### Core visual principles

-   Charcoal and off-white as the main interface foundation
-   GRP green as the primary action/accent color
-   Burgundy as a secondary accent
-   Strong typography
-   Large real photography
-   Editorial/asymmetric layouts
-   Technical grid details
-   Thin borders and dividers
-   Restrained motion
-   Clear hierarchy
-   Minimal decorative effects

### Avoid

-   Generic SaaS layouts
-   Excessive gradients
-   Glassmorphism everywhere
-   Floating blobs
-   Random 3D illustrations
-   AI-generated industrial imagery
-   Fake statistics
-   Unsupported claims
-   Excessive rounded cards
-   Stock handshake photography
-   Overuse of animation

## Primary Goals

1.  Establish a credible digital presence.
2.  Clearly communicate the company's five licensed activity areas.
3.  Generate qualified quote requests.
4.  Make contact/WhatsApp access immediate.
5.  Provide a scalable structure for fleet and project content.
6.  Build a reusable component system rather than a collection of
    one-off pages.
7.  Leave room for a future admin/CMS and backend.

## Content Integrity Rule

Do not invent company history, client names, project counts, fleet
specifications, certifications, awards, testimonials, years of
experience, or performance statistics.

Anything not verified should be represented as a future content field or
marked `TBD`.
