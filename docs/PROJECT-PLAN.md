# Project Plan

## Product Vision

Create a professional digital presence for Grand Route Transport and
General Maintenance that converts visitors into genuine business
enquiries.

The product should combine:

-   Corporate credibility
-   Clear service communication
-   Strong visual identity
-   B2B conversion
-   Mobile usability
-   Future content management

## Target Users

### 1. Business/Procurement Visitor

Needs:

-   Company credibility
-   Service information
-   Contact information
-   Quote request

### 2. Operations/Project Manager

Needs:

-   Transportation options
-   Equipment options
-   Maintenance capabilities
-   Fast enquiry channel

### 3. Existing Client

Needs:

-   Contact details
-   Service access
-   Quick communication

## Core User Goals

``` text
Understand → Trust → Enquire
```

The site should minimize the distance between these three steps.

## MVP Scope

### Included

-   Home
-   About
-   Services
-   Service detail pages
-   Fleet/equipment framework
-   Industries
-   Contact
-   Request Quote
-   Responsive design
-   WhatsApp CTA
-   SEO foundation

### Not required for initial MVP

-   Full customer portal
-   Online payments
-   Complex booking engine
-   Public user accounts
-   Advanced analytics dashboard
-   Large CMS

These can be considered later.

## Phase 2 Features

Potential additions:

-   Admin dashboard
-   Quote management
-   Fleet management
-   Project management
-   Content management
-   Email notifications
-   Arabic localization
-   Lead analytics

## Success Criteria

The project is successful when:

1.  Visitors understand the company's core capabilities within seconds.
2.  All five licensed activity areas are clearly represented.
3.  Visitors can request a quote without confusion.
4.  Contact details are immediately accessible.
5.  The design is visually distinctive without being excessive.
6.  No unsupported company claims are presented.
7.  The website works well on mobile.
8.  The architecture can support future backend functionality.

## Non-Goals

The website should not attempt to:

-   Invent a corporate history
-   Manufacture social proof
-   Pretend to have clients/projects not supplied
-   Display unverified fleet specifications
-   Replace an internal logistics management system
-   Become an unnecessarily complex SaaS application

## Definition of Done

A page is considered complete when:

-   [ ] Responsive
-   [ ] Accessible
-   [ ] Visually consistent
-   [ ] Content approved
-   [ ] SEO metadata added
-   [ ] Loading states considered
-   [ ] Error states considered where applicable
-   [ ] Tested on mobile and desktop
-   [ ] No placeholder production content remains
